# 前端视觉规范（短剧版 Kazumi）

> 建立：2026-10-24 · 第一轮决策已定稿
> 参照：`reference/Kazumi` tag `2.4.2`（commit `7cb58d7d`），**以源码为准，不以下图为准**
> 关联：`docs/PLAN.md`、`lib/ui/theme/md3_tokens.dart`、`lib/ui/core/app_theme.dart`

## 0. 目标与判据

**目标**：在 hoshi 上复现 Kazumi 的视觉语言与交互语法，并按短剧内容做最小适配。
自动化测试保证的是**结构**，人眼保证的是**观感**；两者都不能替代对方。

### 0.1 「像素级对齐」的定义

不做跨平台叠图（中文字形渲染在 Windows / Android / macOS 上不同，叠图必然假红）。
判定方式：

| 项 | 判定 |
| --- | --- |
| 视口 | 390×844（手机竖屏）、844×390（手机横屏）、900×1200（平板）、1280×800（桌面）、1600×1000（宽屏） |
| 几何 | 关键节点的 `dx / dy / width / height` 与参照常量一致，容差 ±1dp |
| 色值 | 以种子色映射后的角色色比对（`primaryContainer` 对 `primaryContainer`），**不比色相** |
| 字形 | 只比字号、行高、字重、字间距，不比字形像素 |
| 动效 | 只比时长与曲线类型，不比插值帧 |

### 0.2 四层标尺

每个页面都要在四个层面各过一次：**令牌 → 结构 → 组件 → 动效**。
矩阵里任何一格都不能是「看起来差不多」。

## 3. 刻意偏离登记

偏离必须登记，否则下一轮会被当成 bug 修掉。

1. **品牌色靛蓝**（Q4）。所有角色色按 `ColorScheme.fromSeed(seed: 0xFF2F4F86)` 映射；不得为了「像 Kazumi」把某处写死绿色。
2. **内容染色 15%**（Q5）。内容书架 = `Color.alphaBlend(primaryContainer.withValues(alpha: .15), surface)`，深色下底色换成 `surfaceContainerLowest`；导航/工具栏 = `surfaceContainer`。Kazumi 是内容全量染色，这是刻意的减量。
3. **海报固定 0.65**（Q7）。源封面为 3:4 时会上下裁切，统一 `BoxFit.cover` 居中。这是已知取舍，不按源比例自适应。
4. **信息卡右列**（S5）。固定「总集数 + 上线日期」两行；热度（或评分）有值时追加第三行，缺失时不占位。原「集数」单独成行会丢日期，已否。
5. **来源切换**（S2）。按 2.4.2 的 `source_sheet_view.dart` 做底部弹层 + 每源状态文案；`img_3.png` 的连体 tab + 状态点属于旧版，**明确不复刻**。
6. **双播放形态**（Q6）。Kazumi 只有横屏影院；竖屏沉浸流按短剧习惯新增，不复用 Kazumi 的控件逻辑。
7. **移除 TV 模式**（S3）。Kazumi 没有 TV 分支；移除后本项目的分支数少于 Kazumi。
8. **截图不进 CI**（S4）。Kazumi 也没有截图门禁；我们保留人工基线。
9. **桌面自绘标题栏**（V2-4）。Windows / macOS 使用自绘窗口 chrome（拖拽区、窗口按钮、窗口尺寸记忆、托盘与关闭行为），Kazumi 走系统标题栏。该差异只在桌面窗口壳层，不进入页面内容区；页面几何仍按 §0.1 的视口比对。

## 4. 阶段计划

### V0 · 基线与减法

**任务**

1. 移除 TV 模式（见 §6），先做减法再对齐，避免每个页面都带 `isTelevision` 分支。
2. 建立「参照常量表」：把 Kazumi 的硬编码几何集中到本文件与 `md3_tokens.dart`，禁止页面再写魔数。
3. 废止旧判据「设置两栏」（在 V5 执行）。

**自查**：全仓 `isTelevision` / `tv-` 零命中；`dart analyze lib` 无 error。

### V1 · 令牌与层次

**任务**

1. 新增令牌：`Md3Surface.shelfTint = .15`、`Md3Surface.blurSigma = 15`、`Md3Surface.blurDownsample = .5`、`Md3Surface.backdropOpacity = .4`、`Md3Motion.fadeIn = 120ms`。
2. 页面转场表：Android/iOS `CupertinoPageTransitionsBuilder`，Windows/Linux `FadeUpwardsPageTransitionsBuilder`，设置子页 `FadeForwardsPageTransitionsBuilder`。
3. 图片 120ms 淡入（`frameBuilder` + 控制器），替掉现在的硬切。
4. 清理只出现在契约测试里的令牌（`listGap`、`cardTitle` 等）。

**验收**：页面无私写色值/圆角/时长；契约测试覆盖全部新增令牌；仓库内 `Colors.` 直接出现在页面层的次数为 0（`app_theme` 与语义色除外）。

### V2 · 外壳与导航

**任务**

1. rail 回到 Kazumi：宽 72、`groupAlignment: 1`、`labelType: selected`、顶部只有搜索 FAB。
2. 层次改为 §3-2：内容 15% 染色，导航 `surfaceContainer`。
3. 竖屏底部导航保持 80 高、pill 指示器；核对两侧留白与 Kazumi 一致。
4. 页面转场按 §V1-2 接入；桌面自绘标题栏与 Kazumi 的差异登记。

**验收**：390 / 1280 两视口下 rail 与底栏几何 ±1dp；切换 tab 保持滚动与筛选（既有断言）；截图与参照并排人工比对通过。

### V3 · 首页与目录

**任务**

1. 推荐位并入同一 `CustomScrollView`，删掉独立 Scaffold/AppBar 分支。
2. 顶栏动作 5 → 3（搜索、排序、更多），其余进溢出菜单；同步改 4 个直接 tap 的用例。
3. 站源切换器继续充当大标题；分类下拉保持 240×350 上限。
4. 网格、骨架、遥控网格（若仍存在）统一走 `Md3Grid`。

**验收**：首屏骨架与真实网格同列数同行高；滚动 0→底部无跳版；动作 key 用例全绿。

### V4 · 详情

**任务**

1. 折叠标题字号插值（`lerpDouble` 与首页同一套曲线）。
2. 来源切换改为 2.4.2 的底部弹层（每源一行状态文案），删掉现有的「来源」tab。
3. 选集：100 集网格、区间跳转、已看进度标记、连播开关。
4. 收藏按钮浮在封面左下（Kazumi 的 `CollectButton` 位置）。

**验收**：头 412 / 卡 300 / 宽 950 / 模糊参数与参照一致；展开态与收起态各一张截图；100 集不卡顿。

### V5 · 其余页面

**任务**：我的（28 圆角 + secondary/tertiary/surface 容器色）、设置（二级列表页 + FadeForwards）、榜单（时间表映射）、搜索（筛选弹层）、下载、插件/规则卡、站源、本地媒体、合并队列、解锁/档案。

**验收**：每页的「令牌/结构/组件/动效」四格无 ⬜；空态、加载、内容三态都有截图。

### V6 · 播放器双形态

**任务**（细节待 §7-Q7 定稿）

1. 竖屏沉浸流：单集全屏、上下滑换集、相邻集预加载、覆盖层（进度、选集、倍速、弹幕）。
2. 横屏影院：照 Kazumi `player_item_panel` 的面板语法（顶部标题/返回、底部进度与操作、手势 HUD）。
3. 竖屏 → 横屏的触发规则（旋转、全屏按钮、视频比例）。
4. 弹幕在两种形态下的轨道与开关。

**验收**：竖屏、横屏、全屏三态截图；连续滑动 20 集无重复解码与黑屏；手势与系统返回不冲突。

### V7 · 动效、可访问性与性能

**任务**

1. `reduce motion` 全覆盖（现仅 `Md3Motion.of` 部分接入）。
2. hover / focus / 右键菜单：合集、下载任务、集数按钮补齐。
3. 键盘 Tab 顺序与焦点陷阱审查。
4. 模糊背景的降采样与缓存；`ImageFiltered` 不在滚动中重复创建。
5. 字体保持 MiSans 全量（8.1MB），不做子集化。

**验收**：`flutter analyze` 0 error / 0 warning；`scripts/check_perf_budget.py` 通过；严格模式下连续滚动无掉帧。

## 7. 第三轮决策（已定稿）

1. **竖屏流默认一滑一集**；连续流作为可配置项保留，不设默认。
